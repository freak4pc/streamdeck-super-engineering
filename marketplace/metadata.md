## Short description

See and control your live super.engineering sessions from any Stream Deck key layout.

## Description

Bring your super.engineering sidebar to Stream Deck. Session keys stay in the same visible order as
the app and update live as agents work, wait for attention, or become idle.

Each key shows the session title, project, Git additions and deletions, active selection, and pull
request lifecycle and check status. Press a session to focus it instantly. Hold a non-primary session
to arm safe worktree deletion, then tap again to confirm.

The grid adapts to the Session Slot keys visible on each connected device. Add as many slots as you
want, then use optional Previous Sessions and Next Sessions keys for independent per-device paging.
It supports Stream Deck Mini, Stream Deck, Stream Deck XL, Stream Deck Mobile, Stream Deck +, Stream
Deck Neo, Virtual Stream Deck, Galleon 100 SD, and Stream Deck + XL.

Requires macOS 14, Stream Deck 7.1, and super.engineering with sc API v21 or newer. GitHub CLI is
optional and adds live CI check colors for open pull requests. The plugin runs locally, contains no
telemetry, and uses only public Stream Deck SDK APIs.
